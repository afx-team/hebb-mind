Why Hippocampus?

Built on neuroscience principles, designed for production.

🧠

Memory Consolidation

Automatic agent classifies memories into semantic, episodic, preference, and procedural partitions — just like the human brain's memory systems.

🔄

Dynamic Forgetting

TTL formula inspired by Ebbinghaus: frequently accessed, high-importance memories live longer. Neglected memories fade away naturally.

🔬

Semantic Search

Three-signal retrieval: recency, importance, and vector relevance. Tunable weights let you control what matters most.

🌐

Knowledge Graph

Tags extracted during consolidation form a graph of connected concepts. Explore relationships between memories visually.

⚡

Zero-Config Start

SQLite backend means hippocampus init && hippocampus start is all you need. Upgrade to PostgreSQL for production.

🖥

Web Console

Built-in dark-themed dashboard for memory CRUD, semantic search with weight tuning, partition management, and graph visualization.

Architecture

Brain-inspired memory lifecycle: ingest, consolidate, retrieve, forget.

Write Memory ──> HIPPOCAMPUS (Working Memory)
                        │
                 Consolidation Agent
                 ├── Agentic RAG recall
                 ├── LLM classification
                 ├── Conflict resolution
                 └── Tag extraction ──> Knowledge Graph
                        │
          ┌─────────────┼─────────────┐
     SEMANTIC      EPISODIC     PREFERENCE    PROCEDURAL
      Facts         Events       Likes         Skills
                        │
                  Forgetting Job
                  TTL = base * (1 + log(access)) * importance * e^(-decay * t)
                        │
                  Expired memories removed

Simple API

RESTful endpoints for every operation. Interactive docs at /docs.

Store a Memory

POST /api/v1/memories

{
  "content": "User prefers dark mode",
  "tags": ["preference", "ui"],
  "importance_score": 7.5
}

Search Memories

POST /api/v1/search

{
  "query": "UI preferences",
  "top_k": 5,
  "weight_relevance": 2.0
}

Create Partition

POST /api/v1/partitions

{
  "id": "mem_project",
  "name": "Project Context"
}

Explore Graph

GET /api/v1/graph/neighbors/python
    ?depth=2

GET /api/v1/graph/path
    ?from=python&to=ml
