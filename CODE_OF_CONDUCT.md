# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, by reference.
Read the full text at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in any project channel — issues, pull requests, discussions
— you agree to abide by its terms.

## Reporting

To report unacceptable behaviour, open a private GitHub Security Advisory at
<https://github.com/afx-team/hebb-mind/security/advisories/new>, or open
an issue titled `conduct: contact request` (no details) and a maintainer
will reach out privately. Reports are handled confidentially.
